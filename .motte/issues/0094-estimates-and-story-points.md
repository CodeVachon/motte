## Description

Weight progress by effort rather than by issue count, so an epic with one large child and nine small ones reports honestly.

## Notes

### 2026-08-05T15:50:26Z — claude (agent)

Declined, and recorded so it is not proposed again from scratch. Progress by issue count is honest at the scale this tool is for, and an effort field invites the ceremony motte exists to avoid — grooming, re-estimating, arguing about whether a three is a five. The real answer to a lopsided epic is to split the large child, which the tool already makes cheap and which improves the plan rather than the arithmetic. Revisit only if somebody is using motte for work where a forecast is actually needed.
